# Where2Night

小程序名：今晚不开卡

面向成年夜生活新手和异地玩家的城市夜生活入门地图。首版覆盖上海、杭州的代表性夜店，帮助用户快速判断去哪、怎么玩、是否适合自己。

## 当前阶段

- 首发城市：上海、杭州
- 苏州：验证首版后再加入
- 首批内容：独立夜店、INS 综合体及内部空间
- 暂不包含：陌生人匹配、付费组局、商家广告后台

## 项目文件

- `docs/mvp-prd.md`：首版产品范围和验收标准
- `data/venues.csv`：首批场所资料表
- `index.html`：MVP 静态原型入口
- `app.js` / `styles.css`：场所筛选、详情、测试和样式

## 本地预览

在项目根目录启动静态服务后，打开 `http://127.0.0.1:4173/`。
